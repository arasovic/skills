# Skills

A curated collection of agent skills I use across projects.

## Install

```sh
npx skills add arasovic/skills -g
```

## Skills

- [**session-handoff**](./skills/session-handoff/SKILL.md): Generate a comprehensive handoff prompt so work can continue seamlessly in a new session.
- [**no-jargon**](./skills/no-jargon/SKILL.md): Report to someone who owns the product but does not read the code.
- [**plan-map**](./skills/plan-map/SKILL.md): Turn a long implementation plan into a one-screen visual map the decision-maker reads instead of the document.
