# Zoom Out

Step back from the current tactic and reassess the active task.

1. Recover the user's actual goal from the conversation. State what a successful outcome would look like.
2. Examine the wider context that could change the approach: surrounding flows, dependencies, constraints, and affected people. Use the task's own terminology.
3. Challenge the assumptions driving the current approach against available evidence. Identify what was overlooked and whether the current tactic addresses the underlying problem.
4. Recommend continuing or changing direction. Explain the main reason and any meaningful tradeoff. Keep the recommendation tied to the user's goal and existing scope.

Report the big picture, the most consequential blind spots, and the recommendation concisely. Gather missing evidence when it could change the recommendation; ask the user only for decisions or information the available context cannot supply.
